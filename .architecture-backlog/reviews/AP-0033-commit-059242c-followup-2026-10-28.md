## Residual Risks

- GitHub recommends avoiding self-hosted runners for public repositories because forked pull requests can execute untrusted code on a runner. This workflow routes only the main-branch manual cutover job to the runner; the ephemeral lifecycle and environment approval still need to be provisioned and verified. See [GitHub self-hosted runner security guidance](https://docs.github.com/en/actions/how-tos/manage-runners/self-hosted-runners/add-runners).
- The gate validates a backup attestation but does not create or restore backups.
